# Mini-SI d'entreprise durci, supervisé et restaurable

## Présentation

Projet de conception et de déploiement
d'un système d'information d'entreprise.

## Objectifs

- Concevoir une infrastructure réseau.
- Durcir les systèmes.
- Automatiser les configurations.
- Superviser la sécurité.
- Tester les sauvegardes et la restauration.

## Technologies

- Proxmox
- Debian
- Windows Server
- Terraform
- Ansible
- Wazuh
- Git et GitHub
